# 居服員外勤緊急事件數位口袋書

本專案將居服員外勤時可能遇到的緊急或異常事件，整理成簡單、清楚且適合手機操作的數位口袋書，讓居服員可以快速判斷狀況、查看處理步驟並完成通報。

## 一、專案目的

讓居服員在外勤遇到緊急或異常事件時，可以快速：

1. 判斷事件類型。
2. 查看處理步驟。
3. 撥打 119、110 或聯絡督導。
4. 降低慌張與處理錯誤。

## 二、使用對象

- 以居服員為主要設計對象。
- 也可供居督及機構同仁使用。

## 三、網站內容

首頁分成六大類，順序如下：

| 順序 | 事件分類 |
| --- | --- |
| 1 | 身體突發狀況 |
| 2 | 照顧意外 |
| 3 | 人身安全 |
| 4 | 交通事故 |
| 5 | 環境安全 |
| 6 | 服務未遇 |

點選分類後，可以看到：

- 事件名稱
- 處理步驟
- 重要提醒
- 119、110 及督導電話

## 四、操作方式

1. 使用手機掃描 QR Code，進入網站。
2. 選擇目前遇到的事件分類。
3. 點選符合現場狀況的事件。
4. 依照畫面顯示的處理步驟操作。
5. 必要時撥打 119、110 或聯絡督導。

## 五、介面設計

- 以手機操作為主。
- 掃描 QR Code 即可進入。
- 不用下載、不用登入。
- 使用大字體及大按鈕。
- 文字簡單、口語化。
- 返回鍵按一次即可回到上一頁。

## 六、製作流程

1. 蒐集緊急事件資料。
2. 整理事件分類及處理流程。
3. 將專業文字改成簡單易懂的用語。
4. 製作手機版網站。
5. 請居服員及居督進行測試。
6. 根據測試意見修改內容與介面。
7. 完成公開網址、QR Code 及成果報告。

## 七、預期成果

完成一個讓居服員在緊急時可以「快速找到、看得懂、馬上照著做」的數位口袋書。
